
Hasta ahora viste contenedores **secuenciales** (`array`, `vector`, `deque`, `list`), donde los elementos se acceden por **posición**. Los contenedores **asociativos** cambian la idea: los elementos se acceden por **clave** (*key*), no por posición.

## Los dos grandes grupos

### 1. Ordenados (basados en árbol balanceado, normalmente rojo-negro)

Mantienen los elementos **siempre ordenados** por la clave (con `operator<` o un comparador propio).

| Contenedor                | Qué guarda          | ¿Claves repetidas? |
| ------------------------- | ------------------- | ------------------ |
| **`std::set<K>`**         | Solo claves         | No                 |
| **`std::multiset<K>`**    | Solo claves         | Sí                 |
| **`std::map<K, V>`**      | Pares clave → valor | No                 |
| **`std::multimap<K, V>`** | Pares clave → valor | Sí                 |

Complejidad de búsqueda, inserción y borrado: **O(log n)**.

### 2. No ordenados (basados en tabla hash)

Se llaman `unordered_set`, `unordered_multiset`, `unordered_map` y `unordered_multimap`. No tienen orden y su complejidad promedio es **O(1)** (en el peor caso O(n) si hay muchas colisiones).

## Ejemplo con `std::map`

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> edades;

    edades["Ana"] = 25;                 // inserta con []
    edades.insert({"Luis", 30});        // inserta con insert
    edades.emplace("Carla", 22);        // construye en sitio

    std::cout << edades["Ana"] << "\n"; // 25
    std::cout << edades.at("Luis") << "\n"; // 30 (lanza excepción si no existe)

    // Recorrido: sale ORDENADO por clave (Ana, Carla, Luis)
    for (const auto& [nombre, edad] : edades) {
        std::cout << nombre << ": " << edad << "\n";
    }

    // Buscar
    if (auto it = edades.find("Pedro"); it != edades.end()) {
        std::cout << "Encontrado\n";
    } else {
        std::cout << "No existe\n";
    }

    edades.erase("Ana");
}
```

## Ejemplo con `std::set`

```cpp
std::set<int> s{5, 1, 3, 3, 1};   // los duplicados se ignoran
// contenido: 1 3 5 (ordenado)
s.insert(4);                      // 1 3 4 5
bool existe = s.contains(3);      // C++20
```

## Cosas importantes a recordar

- **`operator[]` en `map` inserta** si la clave no existe (crea un valor por defecto). Si solo quieres consultar, usa `at()` o `find()`.
- Los elementos de un `map` son `std::pair<const K, V>`: **la clave es constante**, no puedes modificarla.
- Los iteradores recorren en orden de clave (en los ordenados), y **no se invalidan** al insertar otros elementos (solo el del elemento borrado).
- Para usar un tipo propio como clave en `map`/`set` necesitas definir `operator<` (o un comparador); en los `unordered_*` necesitas `std::hash` y `operator==`.
- No hay acceso aleatorio por índice: no existe `m[3]` como posición, solo por clave.

## ¿Cuándo usar cada uno?

- **`map` / `set`**: cuando necesitas los datos ordenados o recorrer por rangos (`lower_bound`, `upper_bound`).
- **`unordered_map` / `unordered_set`**: cuando solo importa buscar rápido y no el orden.
- **`multi*`**: cuando una clave puede aparecer varias veces (por ejemplo, varios cursos por alumno).
