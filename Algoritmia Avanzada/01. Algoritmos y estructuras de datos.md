## Jerarquía de abstracción 

- Los datos se describen con **Estructuras de Datos Fundamentales** de forma abstracta. 
- La organización de los datos en alguna forma son **Estructuras de datos**.
- La secuencia de operaciones realizadas a los datos se le llama **Algoritmos**.
- Una aplicación en la vida real son las **Estructuras de datos** mas los **Algoritmos**.

![[Pasted image 20260921111055.png]]

Mundo real **->** quiero resolver un problema **->** ADT *que necesito representar y con que operaciones* **->** Estructura de datos *Como lo voy a guardar y organizar* **->** Algoritmos *Como hago las operaciones* **->** Aplicación
